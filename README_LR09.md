# Лабораторна робота 9 — CSS Grid та адаптивна верстка

Студент: Лавренко Дмитро, група 122КН.

## Що реалізовано

- мобільний каркас сторінки на Grid з іменованими областями;
- двоколонкова структура `sidebar + main` від 768 px;
- ширина sidebar через `clamp(240px, 25vw, 280px)`;
- адаптивна галерея `auto-fit + minmax()`;
- журнальний акцент: перша картка галереї займає 2 × 2 клітинки;
- блок статистики без окремих медіазапитів;
- адаптивний `h1`, контейнер, таблиці та сенсорні цілі 44 × 44 px;
- темна тема й режим зменшення руху збережені з попередніх робіт;
- окрема сторінка `docs/lab9-experiments.html` з усіма дослідами.

## Що показати викладачу

1. Відкрити `index.html` і змінити ширину вікна: 320, 375, 768, 1024 та 1440 px.
2. На 768 px показати дві області `sidebar + main`; на телефоні — один стовпець.
3. Відкрити `gallery.html`: картки перебудовуються автоматично, перша картка на широкому екрані має розмір 2 × 2.
4. В DevTools вибрати `body.page` і ввімкнути значок Grid, щоб показати треки та області.
5. Відкрити `docs/lab9-experiments.html` і пояснити `fr`, лінії, `auto-fit`, `auto-fill`, `minmax()` та `dense`.
6. Перевірити масштаб 200% і відсутність горизонтального прокручування.

## Скриншоти, які треба зробити власноруч

- завершений 28 рівень Grid Garden;
- Grid Inspector для `body.page`;
- сторінка на 375 px, 768 px і 1440 px;
- Lighthouse Performance та Accessibility;
- WAVE без помилок;
- CSS Validator без помилок.

Ці скриншоти залежать від локального браузера та особистого проходження вправи, тому їх не підмінено вигаданими результатами.
