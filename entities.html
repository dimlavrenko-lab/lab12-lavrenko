Символьні сутності HTML

Символьні сутності використовують для запису спеціальних символів, які мають особливе значення в HTML або відсутні на звичайній клавіатурі.

Основні символьні сутності HTML
Код Вигляд Призначення
&lt;<Знак «менше»
&gt;>Знак «більше»
&amp;&Амперсанд
&quot;"Подвійні лапки
&apos;'Одинарні лапки або апостроф
&nbsp; Нерозривний пробіл
&copy;©Знак авторського права
&reg;®Зареєстрована торгова марка
&trade;™Торгова марка
&euro;€Символ євро
&pound;£Символ фунта стерлінгів
&yen;¥Символ єни
&cent;¢Символ цента
&mdash;—Довге тире
&ndash;–Коротке тире
&laquo;«Ліва кутова лапка
&raquo;»Права кутова лапка
&times;×Знак множення
&divide;÷Знак ділення

Підказка

Сутності дають змогу безпечно показувати службові символи HTML у тексті.
